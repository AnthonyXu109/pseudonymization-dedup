# Follow-up experiments v12 (written 2026-10-06 21:15 PT before running)
Prompted by round-5 reviews. Exploratory; all results reported whatever their direction.

## E12. Curator-side re-detection and collapse on released text (reviewer B, top request)
A curator holding only released text runs its own recognizer (spaCy en_core_web_lg + the same regexes) on each released
document and replaces every detected span by its type token ([PERSON], [DATETIME], ...) before shingling.
Released text: FAKER-DOC and SUR-DOC (also ALIAS-DOC, where the curator instead maps [TYPE_k] to [TYPE] by regex).
(a) TAB, Table V setting (gold spans for the release, 1,268 originals + 400 paragraph copies, exact Jaccard 0.7,
components): recall, lost, residual, Delta lost vs RAW with the cluster bootstrap (2,000, seed 20261001).
(b) Pair recall on second-source copies (detector spans for the release): ECtHR 1,000 pairs, web 2,000 pairs,
exact Jaccard >= 0.7, FAKER-DOC and ALIAS-DOC.

## E13. Keyed MinHash on raw text (reviewer A, top request)
Each holder hashes its raw word 5-grams with HMAC-SHA256 under a shared key (no identifier marking) and shares only
shingle hashes / signatures. TAB, Table V setting, exact Jaccard over keyed 64-bit shingle ids. Expected: identical to
RAW up to hash collisions, independent of markers.

## E14. Faker-dictionary baseline for the surrogate-exposure test (reviewer B)
Setting of E6 (TAB, FAKER-DOC over detector spans, 400 original-copy pairs, candidates = rare capitalized words).
Attacker dictionary: capitalized tokens of 200,000 values per kind (name, company, city, date, country) from Faker en_US
with a different seed (attacker knows the library, not our pools). Rules: one copy minus dictionary; two copies; two
copies minus dictionary. Precision and recall for missed names as in E6.

Outputs: results/v12/*.json. Script: exp_v12.py.
