# Follow-up experiments v8 (written 2026-10-06 before running)

Motivation: reviewer requests from the 2026-10-06 review rounds that can be answered with existing data and code.
These are exploratory checks prompted by reviews, not pre-registered confirmations. All results are reported whatever
their direction.

## E1. Decide on released text with recognizable pseudonyms collapsed (reviewers C M2, D M2)
Question: can a curator who holds only the released text recover copy detection by collapsing recognizable pseudonyms?
Setting: identical to Table IV (TAB, gold first-annotator spans, 1,268 originals + 400 paragraph copies, word 5-grams,
exact Jaccard, theta = 0.7, connected components).
Decision representations:
- SUR-DOC-COLLAPSED: SUR-DOC release, then every token matching `zq[a-z]{10}` replaced by `[PII]`.
- HASH-COLLAPSED: HASH-ENTITY release, then every 64-hex token replaced by `[PII]`.
Reference rows recomputed in the same script: RAW, SUR-CORPUS, MASK, SUR-DOC (must reproduce Table IV: recall
364/364/363/17, lost 11/5/25/0).
Metrics: recall (copy in original's component), lost (cases with no retained representative), paired difference in
lost vs RAW with the cluster bootstrap over components of the union of the two graphs (2,000 resamples, seed 20261001),
and residual duplicates (copies whose case keeps two or more representatives).

## E2. Two holders with different markers, shared key (reviewers A M8, B M9, C M1)
Question: does the shared-key (SUR-CORPUS) decision keep its recall when originals and copies are marked by different
detectors, as with independent data holders?
Setting: same TAB documents and copies as E1. Decision on SUR-CORPUS text. Marking variants:
- gold/gold (reference, = Table IV row), detector/detector (spaCy en_core_web_lg on both),
- gold originals / lg-detector copies,
- lg originals / sm copies (spaCy en_core_web_sm 3.8 run on the 400 copies, same regexes and type map).
Metrics as in E1. Expected direction (stated before running): recall drops when markers differ.

## E3. Marking-scope ablation by entity type (reviewer D M4)
Question: which identifier types drive the loss under SUR-DOC?
Setting: second-source copies of ECtHR (1,000 pairs) and web (2,000 pairs), detector spans from the main runs,
exact word-5-gram Jaccard between each original and its copy, theta = 0.7 (pair recall, as in Table I).
Scopes: PERSON; PERSON+LOC; PERSON+LOC+DATETIME; full detector set (as in Table I).
Metrics: SUR-DOC pair recall, RAW pair recall, median m_doc of originals.

Outputs: results/v8/e1_e2_tab.json, results/v8/e3_scope.json. Script: exp_v8.py.
